# eStore - iPhone Online Shop(lab)

![Website](https://img.shields.io/badge/Website-eStore-blue) ![HTML](https://img.shields.io/badge/HTML5-orange) ![CSS](https://img.shields.io/badge/CSS3-blue) ![JavaScript](https://img.shields.io/badge/JavaScript-yellow)

**eStore** is a simple e-commerce website built using **HTML, CSS, and JavaScript**. It showcases iPhone products with cart functionality, and includes basic login and registration pages.

## 📌 Features

- **Homepage**
  - Navigation bar with links to Home, About, Contact, and Products.
  - Login/Register buttons in the header.

- **Products Page**
  - Displays a list of iPhones with image, price, and description.
  - “Add to Cart” button for each product.

- **Cart Page**
  - Shows products added to the cart.
  - Adjust item quantity and remove items.
  - Displays subtotal, tax, and total.
  - Checkout button (UI only, no backend).

- **Login & Registration**
  - Front-end forms for login and registration.
  - Basic client-side validation for the registration form.
