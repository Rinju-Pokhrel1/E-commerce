# 🛒 Estore – PHP E-commerce Project

This is the **PHP-based version** of the **Estore** project, located in the `php` branch.  
It is a simple e-commerce application built using **PHP, MySQL, HTML, CSS, and JavaScript**, designed to run on **XAMPP (Linux)**.

---

## 📌 Branch Information
- **Branch:** `php`
- **Technology:** PHP + MySQL
- **Server:** Apache (XAMPP)
- **Role-based dashboards:** Admin & User

---

## ⚙️ Requirements

- Linux OS
- XAMPP (Apache + MySQL)
- PHP 8.x
- Git
- Web Browser (Chrome / Firefox)
- VS Code (optional)
